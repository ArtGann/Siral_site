# SIRAL Corporation — Golden Orbit

## Обновление: полный сайт, 6 сентября 2026

Текущая версия содержит 15 содержательных страниц и 404: главная, каталог, шесть отдельных услуг, About, Approach, Engagements, Contact и три юридические страницы. Полный разбор — `SIRAL-Research-and-Design.md`. Результаты проверки новой версии — `design-qa-v2.md`; разделы ниже описывают первоначальную одностраничную версию.

Реализованы фильтры, навигация по реальным URL, история браузера, выбор задачи, интерактивные этапы работы, FAQ, мобильное меню, перенос услуги/формата в обращение, проверка полей, просмотр и копирование письма. Сборка создаёт 16 HTML-страниц с отдельными заголовками и описаниями. Контактная форма готовит письмо в почтовом клиенте, автоматическая отправка и CRM не подключены.

Production SEO подготовлен для `https://siralstrategy.com`: canonical URL, Open Graph/Twitter metadata, sitemap, robots.txt, favicon/app icons, Organization JSON-LD и корректный HTTP 404. В Terms оставлен исходный выбор юрисдикции, который компания должна уточнить. Ручные действия после деплоя (Google Search Console и DMARC) перечислены в `RELEASE_SEO_CHECKLIST.md`.

Интерактивный прототип сайта по выбранному первому концепту: светлый фон, тёмно-синяя типографика, золотой глобус и оригинальный логотип SIRAL с существующего сайта.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev -- --host 0.0.0.0
```

Сборка:

```sh
npm run build
```

Сборка создаёт клиентские файлы в `dist/client` и сохраняет подготовленный runtime для последующего размещения через Sites.

## Что реализовано

- Адаптивная главная страница и мобильное меню.
- Появление элементов, плавное движение глобуса, реакция на указатель и прокрутку.
- Переключатель анимации и поддержка системного reduced motion.
- Три сценария выбора задачи бизнеса.
- Раскрывающиеся услуги, окно плана и интерактивное описание подхода.
- Форма консультации с проверкой полей, просмотром и копированием брифа.

Форма готовит письмо на `info@siralstrategy.com`; отправка происходит только через почтовый клиент пользователя. Серверная отправка, CRM, аналитика и реальное бронирование не подключены. Цены и отзывы, не подтверждённые заказчиком, не добавлены. Существующий сайт не изменён.

## Структура

- `src/App.jsx` — интерфейс и состояния.
- `src/styles.css` — оформление, адаптация и анимация.
- `public/assets` — оригинальный логотип и созданные для концепта изображения.
- `reference/selected-design.png` — выбранный визуальный ориентир.
- `qa` и `design-qa.md` — снимки, сравнения и результаты проверки.

Проверены настольный и мобильный сценарии в облачном браузере. Логотип используется исходным файлом, без перерисовки. Глобус — растровая иллюстрация с анимацией, не WebGL-модель.
